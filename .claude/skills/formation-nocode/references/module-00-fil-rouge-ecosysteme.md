# Module 0 — Fil rouge : prise de hauteur sur l'écosystème

*12 leçons. Contenu réel extrait de la formation (Skool → Cowork).*
*Ce module pose les bases avant de construire : il présente l'écosystème
complet et initie aux 4 outils du système (Airtable, Make, Softr) + Discord
pour la documentation.*

## À savoir avant de commencer

- **Toute la documentation de la formation est sur Discord.**
  Lien du groupe : https://discord.gg/fV3FdE5zTh (demander à rejoindre).
- **État d'esprit enseigné (leçon 1)** : la rigueur informatique. La machine
  fait exactement ce qu'on lui demande ; si un scénario ne marche pas, c'est
  presque toujours une instruction mal formulée, pas le logiciel. Les erreurs
  sont normales et formatrices : les aborder avec humilité, comprendre le
  *pourquoi* plutôt que copier mécaniquement. Regarder les vidéos posément,
  faire pause, revoir si besoin — elles sont denses.
- Objectif du module : **COMPRENDRE** l'écosystème et chaque outil, pour
  pouvoir ensuite construire et se corriger seul.

## Ce que révèle ce module sur l'écosystème enseigné

Le système « NOCODE FORMULA » repose sur **3 outils qui se branchent
ensemble**, chacun couvrant une brique (cf. module 1 pour la théorie) :

1. **Airtable** = la base de données (leçons 3 à 6). On y apprend les
   tables, les **filtres**, les **variables** et **formules**.
2. **Make** = le moteur d'automatisation (leçons 7 à 9). On y apprend les
   **modules**, les **webhooks**, et à lire/construire un **scénario**.
3. **Softr** = les **interfaces utilisateur** (leçons 10-11), branchées sur
   Airtable, avec le **mappage** des informations vers l'écran.

L'ordre d'apprentissage est donc : **Airtable → Make → Softr**, précédé du
schéma global de l'écosystème (leçon 2) et suivi des erreurs fréquentes
(leçon 12).

## Application pour Apart Hotel Berck

- La leçon 2 (« schéma visuel de l'écosystème ») est le bon point de départ
  pour dessiner, sur le cas des 3 appartements de Claudine, ce que chaque
  outil ferait : Airtable = fiche appartements + réservations + prestataires ;
  Make = automatisations (résa → tâche ménage → message) ; Softr = une petite
  appli pour l'équipe.
- Avant de construire quoi que ce soit, rejoindre le Discord pour récupérer
  les templates et la documentation.
